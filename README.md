# Основа

Локальная платформа закрытого профессионального сообщества для разработчиков, инженеров и других IT-специалистов. Сайт, журнал, база знаний, группы и форум работают под одним аккаунтом.

## Реализовано

- публичная стартовая страница без тем и закрытые маршруты после входа;
- регистрация по почте и юзернейму, подтверждение почты, восстановление пароля;
- HttpOnly-сессии, PBKDF2, rate limit и 2FA через TOTP/Google Authenticator или Telegram;
- роли `guest`, `member`, `author`, `expert`, `pro`, `moderator`, `admin` и серверная проверка доступа;
- IPB-подобная структура форума, страницы разделов и обсуждений;
- создание тем и ответов в D1, подписки на разделы/темы и жалобы;
- внутренняя лента уведомлений для ответов, упоминаний, подписок и решений;
- премодерация с назначением ответственного, комментариями и историей решений;
- возврат отклонённой темы автору на редактирование и повторную проверку;
- журнал и база знаний на реальных записях D1 со страницами материалов;
- редактор статей и мануалов с черновиками, проверкой, публикацией и восстановлением версий;
- связь статей и мануалов с обсуждениями форума и серверной защитой PRO;
- интегрированные группы в общей оболочке сообщества;
- бесплатные и PRO-разделы, премодерация коммерческих направлений;
- D1-схема тем, ответов, публикаций, групп, подписок, жалоб и event outbox;
- контракты интеграций для оплаты, уведомлений, рефералов и модерации.

Контент о заработке, рекламе и реферальных программах допускается только в рамках закона, с обязательным раскрытием выгоды автора. Серые и чёрные схемы запрещены.

## Локальный запуск

Требуется Node.js 22.13+.

```bash
npm install
npm run dev
```

Откройте `http://127.0.0.1:3000`. Внешние сервисы и продакшен не используются.

Локальные коды подтверждения показываются в интерфейсе. Для настоящих писем и Telegram скопируйте `.env.example` в `.env.local` и заполните параметры провайдеров. Настоящие секреты в Git не добавляются.

## Основные маршруты

- `/` — публичная стартовая страница;
- `/auth` — регистрация, вход, подтверждение и восстановление;
- `/forum` — защищённый индекс сообщества;
- `/forum/section/[slug]` — раздел форума;
- `/forum/topic/[slug]` — обсуждение;
- `/journal` — редакционный журнал;
- `/journal/[slug]` — отдельная статья из `content_records`;
- `/library` — база знаний и мануалы;
- `/library/[slug]` — отдельный версионный мануал;
- `/editor` — рабочая очередь авторов и редакции;
- `/editor/new` — новый черновик статьи или мануала;
- `/editor/[id]` — текст, статусы и история версий материала;
- `/groups` — клубы и команды;
- `/notifications` — внутренняя лента уведомлений участника;
- `/moderation` — очередь публикаций и жалоб для `moderator`/`admin`;
- `/account/security` — двухфакторная защита.

Схема развития и границы продукта описаны в [`docs/PRODUCT_PLAN.md`](docs/PRODUCT_PLAN.md).

## Ключевые каталоги

- `app` — страницы и API-маршруты;
- `components` — общая оболочка и интерфейс форума;
- `db/schema.ts`, `db/migrations` — D1-схема и миграции;
- `lib/auth` — сессии, криптография и доставка кодов;
- `lib/forum` — каталог разделов, правила, данные и event outbox;
- `lib/integrations` — заменяемые границы внешних сервисов.

Проект остаётся локальным. Публикация и подключение продакшен-сервисов выполняются только по отдельному запросу.
