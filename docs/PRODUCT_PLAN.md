# План платформы «Основа»

## Продуктовая рамка

«Основа» — закрытое профессиональное сообщество для IT-специалистов. Сайт, журнал, база знаний, группы и форум используют один аккаунт, одну систему ролей и общие обсуждения. До отдельного решения проект работает только локально.

Контент о заработке, рекламе и реферальных программах допускается только в законной «белой» модели. Серые и чёрные схемы, чужие данные, мошенничество, вредоносное ПО и инструкции по обходу закона запрещены.

## Архитектура продукта

- **Публичная зона:** только консервативная стартовая страница, регистрация, вход, подтверждение и восстановление доступа.
- **Форум:** иерархия категорий и разделов, темы, ответы, подписки, закрепление, закрытие, жалобы и премодерация.
- **Журнал:** редакционные статьи с отдельной дискуссией на форуме.
- **База знаний:** версионируемые мануалы, автор, дата проверки, уровень доступа и связанная тема обсуждения.
- **Группы:** клубы по интересам и команды; членство в группе не заменяет системную роль.
- **Интеграции:** события сообщества записываются в outbox и позже обрабатываются уведомлениями, аналитикой, Telegram и другими адаптерами.

## Доступ и роли

| Роль        | Возможности                                                  |
| ----------- | ------------------------------------------------------------ |
| `guest`     | Стартовая страница, регистрация и вход                       |
| `member`    | Бесплатные разделы, темы, ответы, подписки и открытые группы |
| `author`    | Возможности участника и собственные редакционные материалы   |
| `expert`    | Авторские материалы с подтверждённой специализацией          |
| `pro`       | Возможности участника и PRO-материалы                        |
| `moderator` | Проверка публикаций, жалобы и управление обсуждениями        |
| `admin`     | Роли, структура, правила, интеграции и полный аудит          |

## Этапы реализации

### Этап 1 — каркас и безопасность

- [x] Публичная стартовая страница и закрытые маршруты сообщества.

- [x] 2FA через TOTP/Google Authenticator и Telegram.
- [x] Роли, бесплатные и PRO-разделы.
- [x] D1-схема пользователей, форума, контента, групп, подписок, жалоб и событий.

- [x] Статьи и мануалы перенесены в `content_records` и связаны с обсуждениями.
- [x] Политика законного контента и обязательное раскрытие партнёрской связи.

### Этап 3 — модерация и редакция

- [x] Очередь премодерации, назначение ответственного, комментарии и история решений.
- [x] Возврат темы на доработку и повторная отправка автором.
